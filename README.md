# Kimberley Scharf GitHub Pages site

Upload the contents of this folder to the root of the GitHub repository used for GitHub Pages.

Files included:
- index.html: the actual web page file GitHub Pages will serve.
- index_source.txt: identical HTML code in a plain text file, useful if your computer opens index.html as a browser preview.
- CNAME: custom domain setting for kimscharf.com.
- .nojekyll: tells GitHub Pages not to process the site with Jekyll.
- robots.txt: permits search engine crawling.
